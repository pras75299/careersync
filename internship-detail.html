Frontend Developer Intern

TechCorp India

Bangalore, India Remote 3 months

About the Role

Join our dynamic frontend team and work on cutting-edge web applications using React, TypeScript, and modern CSS frameworks. You'll collaborate with experienced developers to build user-friendly interfaces and contribute to our growing product suite.

Key Responsibilities

  • Develop responsive web applications using React and TypeScript
  • Collaborate with UI/UX designers to implement pixel-perfect designs
  • Write clean, maintainable, and well-documented code
  • Participate in code reviews and team discussions
  • Work with APIs and integrate frontend with backend services
  • Optimize applications for maximum speed and scalability

Required Skills

React.js JavaScript TypeScript HTML/CSS Git Responsive Design

Preferred Qualifications

  • Currently pursuing or completed Bachelor's degree in Computer Science or related field
  • Previous experience with React.js and modern JavaScript
  • Understanding of RESTful APIs and web services
  • Familiarity with version control systems (Git)
  • Strong problem-solving and communication skills

What We Offer

  • Competitive stipend of ₹15,000 per month
  • Mentorship from senior developers
  • Flexible working hours
  • Certificate of completion
  • Potential full-time employment opportunity
  • Access to learning resources and courses
